One line of horror: a single sentence, under 200 characters, that has to frighten a reader in one breath. The program writes it deterministically to `$MAKEFUN_OUTPUT_DIR/entry.txt` and validates it against the competition gate (1–200 characters, one line, one sentence, no trailing newline).

The line: *"Every night my smart speaker whispers my name in my dead mother's voice, and tonight it finally pronounced it right."* (116 characters)

The scare is earned, not announced — something has been learning to sound like her, and tonight it finally got it right.

## Run it

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written; it defaults to `./output`.
